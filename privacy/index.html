Privacy and your data

This site is a set of static files. There is no analytics, no remote font, no third-party script, no service worker and no server that could receive your ROM. Your file is hashed, run and saved entirely inside this browser tab.

Two kinds of data, two lifetimes

The ROM

By default the ROM lives only in this tab: it survives moving between pages, not a reload or a closed tab. Remembering it writes the bytes to IndexedDB under their digest — never the filename, path, MIME type or filesystem dates.

Save data

Battery SRAM is stored under the ROM's digest with its own format version, byte length and checksum. It is kept even when you forget the ROM, so dropping the same file again picks up where you left off.

Both at once

Gameplay and the save writer stop before either record is removed, so no final flush can recreate the save afterwards. These controls stay available even with no ROM in this tab.

Open in more than one tab?
Tabs are not coordinated in M0. The last write wins, and another open tab can recreate a save you just deleted here. If storage is full or unavailable — private windows often are — you are told, and play continues without saving.

The technical boundary

  • No analytics, remote font, runtime CDN or third-party script is served, and no service worker is registered.
  • The application makes no POST, beacon or WebSocket request; runtime traffic is read-only same-origin assets.
  • ROM and save bytes, file names, paths, metadata and rejected-file digests never enter a URL, header, request body, log or error-report instruction.
  • A Content-Security-Policy limits scripts, workers, connections, fonts and media to this origin's minimum.
  • The WebAssembly build is single-threaded, with no pthreads, no SharedArrayBuffer and no cross-origin isolation requirement.
Reporting a problem
Send only the route, your browser and version, the error code shown on screen and the steps you took. Never attach a ROM, a save file, a screenshot of gameplay or decoded output — none of it is wanted, and none of it would help.
